# 2026년 이음세대 윳놀이

브라우저에서 실행하는 50칸 일렬형/지그재그형 윳놀이 테마 보드게임 진행 앱입니다.

## 목적

전통 윷놀이판이 아니라, 행사/모임에서 사용할 수 있는 보드게임 형태의 진행판을 제공합니다.

- 특별 칸 사전 등록
- 참여자 여러 명 등록
- 50칸 보드판 표시
- 참여자 선택 후 원하는 칸 클릭 이동
- 특별 칸 안내 메시지 표시
- 최종 도착 순위/현재 위치 기준 결과 표시

## 실행 방법

별도 서버 없이 실행할 수 있습니다.

```bash
cd 2026-ieum-yut-game
python3 -m http.server 8080
```

브라우저에서 다음 주소를 엽니다.

```text
http://localhost:8080
```

또는 `index.html` 파일을 브라우저로 직접 열어도 됩니다.

## 사용 방법

### 1. 특별 칸 등록

1. 첫 화면에서 특별 칸 번호, 제목, 설명, 색상을 입력합니다.
2. `특별 칸 저장`을 누릅니다.
3. 필요한 만큼 반복합니다.
4. 설정이 끝나면 `참여자 등록으로 이동`을 누릅니다.

### 2. 참여자 등록

1. 참여자 이름을 입력합니다.
2. `참여자 추가`를 누릅니다.
3. 필요한 만큼 반복합니다.
4. `게임 시작`을 누릅니다.

### 3. 보드 진행

1. 왼쪽 참여자 목록에서 이동할 참여자를 선택합니다.
2. 중앙 보드판에서 원하는 칸을 클릭합니다.
3. 선택된 참여자의 말이 해당 칸으로 이동합니다.
4. 50번 칸에 도착하면 도착 순위가 기록됩니다.

특별 칸에 도착하면 사전에 등록한 안내 메시지가 보드 하단에 표시됩니다.

### 4. 게임 종료

- 모든 참여자가 50번 칸에 도착하면 자동으로 결과 화면으로 이동합니다.
- 중간에 `게임 종료`를 누르면 현재 상태 기준으로 결과 화면을 표시합니다.

## 순위 기준

1. 50번 칸에 먼저 도착한 순서
2. 도착하지 않은 참여자는 현재 위치가 높은 순서
3. 같은 위치이면 등록 순서

## 디자인 방향

Magnific의 보드게임판 참고 이미지에서 보이는 어린이/가족용 보드게임 스타일을 직접 CSS로 재해석했습니다.

- 추석/민속놀이 느낌의 따뜻한 갈색·황금색 배경
- 보름달, 토끼, 연, 벼, 장구, 송편 장식
- 둥근 타일형 보드 칸
- 이어지는 길 형태의 50칸 경로
- 특별 칸 아이콘/색상 강조
- 출발/도착 칸 강조
- 참여자별 원형 컬러 토큰

외부 이미지는 직접 사용하지 않았으며, 저작권 이슈를 피하기 위해 CSS와 이모지 기반으로 자체 구현했습니다.
